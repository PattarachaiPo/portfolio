Requirement Document: บ้านคลองค้าไม้ – Employee & Payroll Management System

Document Version: 2.0 (Owner Sign-off Baseline – Scoped Implementation) Date: 26 November 2026 Project: บ้านคลองค้าไม้ Document Status: OWNER SIGN-OFF – Approved baseline with scoped implementation authorization; unresolved payroll and technical rules remain gated

1. Project Overview

พัฒนาระบบบริหารพนักงานและเงินเดือนสำหรับ บ้านคลองค้าไม้ รองรับการจัดเก็บข้อมูลพนักงาน การลงเวลา การลา การขาดงาน การเบิกเงินล่วงหน้า และการคำนวณเงินเดือน

ระบบนี้เป็นระบบภายในสำหรับฝ่ายบริหาร/HR/Payroll และพนักงาน โดยออกแบบให้ใช้งานผ่าน Responsive Web

1.1 Business Context

ระบบนี้จัดทำขึ้นเพื่อใช้ภายในกิจการ บ้านคลองค้าไม้ สำหรับบริหารข้อมูลพนักงาน การลงเวลาทำงาน การลา การขาดงาน การเบิกเงินล่วงหน้า และการจ่ายเงินเดือน โดยเป็นระบบอิสระ ไม่เชื่อมโยงกับระบบของธุรกิจอื่น

ระบบรองรับพนักงานตามประเภทการจ้างและรูปแบบค่าตอบแทนที่กิจการกำหนด เช่น พนักงานรายเดือน พนักงานรายวัน หรือพนักงานประเภทอื่นที่เพิ่มภายหลังได้

1.2 Objectives

  1. จัดเก็บข้อมูลพนักงานและสถานะการทำงานไว้ในศูนย์กลาง
  2. บันทึกและตรวจสอบการมาทำงาน การลา และการขาดงาน
  3. รองรับรอบ Payroll และวันจ่ายเงินที่กำหนดได้ผ่าน System Configuration (ไม่ hardcode วันที่ 1 และ 15)
  4. รองรับการยื่นคำขอเบิกเงินล่วงหน้าและหักคืนในรอบเงินเดือน
  5. คำนวณรายได้ รายการเพิ่ม รายการหัก และยอดสุทธิอย่างตรวจสอบย้อนหลังได้
  6. ลดการคำนวณด้วยมือและมีรายงานสำหรับผู้บริหาร

2. Scope

2.1 In Scope

  • Employee Profile
  • Employee Type และ Salary Structure
  • Attendance / Time Record
  • Leave Request และ Leave Balance
  • Absence / Late / Early Leave Record
  • Salary Advance Request, Approval และ Repayment
  • Configurable Payroll Period / Pay Schedule and Payroll Processing
  • Earnings / Allowances / Deductions
  • Payslip
  • Approval Workflow
  • Payroll Reports และ Audit Log
  • User Roles และ Permission
  • Export รายงานเป็น CSV/Excel หรือ PDF (รูปแบบไฟล์ให้ยืนยันในขั้นออกแบบ)

2.2 Out of Scope (Initial Release)

  • ระบบสรรหาและสมัครงาน (Recruitment)
  • ระบบประเมินผลงานและ KPI เต็มรูปแบบ
  • ระบบบัญชีแยกประเภท/ลงบัญชีอัตโนมัติ
  • การโอนเงินเดือนผ่านธนาคารโดยตรง (รองรับบันทึกสถานะการจ่ายและช่องทางจ่ายก่อน)
  • การคำนวณภาษีเงินได้บุคคลธรรมดาและประกันสังคมแบบยื่นรายการอัตโนมัติ จนกว่าจะยืนยันข้อกำหนด
  • GPS/Geofencing หรือระบบตอกบัตรด้วยอุปกรณ์เฉพาะ
  • การคำนวณค่าคอมมิชชันจากผลงานแบบอัตโนมัติใน Release แรก (สามารถบันทึกเป็นรายการเพิ่มด้วยมือได้ หากอนุมัติ)

FR-PAY Calculation – Approved Architecture / Rules Pending

สูตรแสดงผลเบื้องต้น:

ยอดสุทธิ = รายได้พื้นฐาน + รายได้เพิ่มเติม – รายการหัก

ตัวอย่างองค์ประกอบ:

  • รายได้พื้นฐาน: เงินเดือนตามสัดส่วนรอบ หรือค่าจ้างรายวัน × วันทำงานที่จ่าย
  • รายได้เพิ่มเติม: OT, เบี้ยเลี้ยง, โบนัส, ค่าตอบแทนพิเศษ (ถ้ามีนโยบาย)
  • รายการหัก: ขาดงาน, Unpaid Leave, มาสาย, Salary Advance คงค้างเต็มจำนวน และรายการอื่นตาม Deduction Configuration
  • รายการหักและพารามิเตอร์ต้องใช้ Typed Configuration และ Rule Catalogue ที่ระบบรองรับ ไม่อนุญาตให้ใส่ Script/SQL/สูตรอิสระ
  • ขาดงาน ลา มาสาย OT และยอดเบิกล่วงหน้าต้องดึงจากข้อมูลจริงของงวดเป้าหมายและคำนวณใหม่ ไม่ใช้ยอดจากงวดก่อน

ข้อควรระวัง: การอนุมัติครั้งนี้ครอบคลุมโครงสร้างและหลักการเท่านั้น สูตร Proration, จำนวนวันฐานหารเงินเดือน, การนับวันทำงาน/วันจ่าย, ผลกระทบของการลา/มาสาย, สูตร OT, การปัดเศษ, ลำดับการหัก และค่าตามกฎหมายยังต้องมี Business Rule และตัวอย่างคำนวณที่เจ้าของงานอนุมัติก่อนพัฒนา Payroll Engine

Payroll Duplicate – Safe-copy behavior

  1. ผู้ใช้เลือก Source Payroll Reference/Run และ Target Period
  2. ระบบสร้าง Payroll Run ใหม่เป็น Draft พร้อม Unique Target Reference (ตัวอย่างรูปแบบ PAY-YYYY-MM-DD) และเก็บ Source Run/Reference
  3. Duplicate ทั้ง Payroll Run เป็นชุด ไม่ต้องเลือก Earning/Deduction ทีละบรรทัด
  4. สร้าง Employee Set ใหม่จากพนักงานที่มีสิทธิ์ใน Target Period
  5. รายการประจำ/โครงสร้างที่เป็นข้อมูลตั้งต้นอาจนำมาเป็น Starting Point ตาม Eligibility และ Validation
  6. ไม่คัดลอก Paid/Closed/Approved Status, Payment Reference, Approval Decision, Payslip หรือ Snapshot เดิม
  7. Attendance, Leave, Absence, Late, OT และ Salary Advance ต้องคำนวณใหม่จาก Target Period
  8. แสดง Preview, รายการที่นำมาใช้/ไม่ใช้ และผล Recalculation ก่อนยืนยันสร้าง Draft

Salary Advance – Full Outstanding Balance

  • ดึง Advance ที่เข้าเงื่อนไขจากยอดคงค้างปัจจุบัน
  • หักเต็มจำนวนยอดคงค้าง ไม่ใช้ยอดจากงวดก่อนและไม่ใช้แผนผ่อนชำระเป็นค่าเริ่มต้น
  • บันทึก Advance Reference, Outstanding Before, Deducted Amount, Outstanding After และ Payroll Reference
  • ป้องกันการหัก Advance เดียวกันซ้ำ
  • หากยอดคงค้างมากกว่า Net Pay ให้สร้าง Exception; ห้ามระบบลด/แบ่งยอดหักหรือทำ Net Pay ติดลบเองจนกว่าจะมี Business Rule อนุมัติ

6. Main Workflows

6.1 Leave Workflow

  1. พนักงานเข้าสู่ระบบและยื่นคำขอลา
  2. ระบบตรวจสอบข้อมูลที่จำเป็นและยอดวันลาคงเหลือ (หากเปิดใช้)
  3. ส่งคำขอไปยังผู้อนุมัติ
  4. ผู้อนุมัติอนุมัติหรือปฏิเสธ
  5. เมื่ออนุมัติ ระบบบันทึก Leave และปรับ Attendance
  6. Payroll ดึงข้อมูลลาไปคำนวณตามประเภทการลา

6.2 Absence Workflow

  1. HR ตรวจพบหรือได้รับแจ้งการขาดงาน
  2. HR บันทึกรายการขาดงานเป็น Pending Review
  3. พนักงานชี้แจงหรือส่งหลักฐาน (ถ้ามี)
  4. HR/ผู้มีสิทธิ์ยืนยันหรือยกเลิกรายการ
  5. รายการที่ยืนยันแล้วจึงถูกส่งเข้า Payroll

6.3 Salary Advance Workflow

  1. พนักงานยื่นคำขอเบิกล่วงหน้า
  2. ระบบตรวจสอบเงื่อนไขและวงเงิน
  3. ผู้อนุมัติอนุมัติ/ปฏิเสธ
  4. Payroll/Finance บันทึกการจ่ายเงินจริง
  5. ระบบสร้างยอดคงค้างและตารางหักคืน
  6. Payroll นำยอดที่ถึงกำหนดไปหักในรอบเงินเดือน
  7. ระบบปรับยอดคงเหลือและแสดงประวัติ

6.4 Payroll Workflow

  1. Payroll Officer เปิดรอบเงินเดือน
  2. ระบบดึงข้อมูลพนักงานและรายการที่เกี่ยวข้อง
  3. ระบบคำนวณรายได้และรายการหักตามกติกา
  4. Payroll Officer ตรวจสอบข้อผิดปกติและ Preview
  5. ส่งให้ผู้มีอำนาจอนุมัติ
  6. อนุมัติและปิดรอบ
  7. บันทึกการจ่ายเงินและสร้าง Payslip
  8. พนักงานเข้าดู Payslip ของตนเอง

10. System Independence

  • ระบบ Employee & Payroll เป็นระบบภายในของบ้านคลองค้าไม้โดยเฉพาะ
  • ไม่เชื่อมต่อหรือใช้ข้อมูลร่วมกับระบบของธุรกิจอื่น
  • ข้อมูลพนักงาน การลงเวลา การลา การขาดงาน การเบิกล่วงหน้า และ Payroll จัดเก็บและบริหารภายในระบบนี้
  • หากต้องการเชื่อมต่อระบบบัญชีหรือระบบอื่นในอนาคต ให้กำหนดเป็นขอบเขตงานเพิ่มเติมแยกต่างหาก

11. Acceptance Criteria

  1. HR สามารถเพิ่มพนักงานและกำหนดรูปแบบค่าจ้างได้
  2. พนักงานสามารถยื่นลาและตรวจสอบสถานะคำขอได้
  3. ผู้อนุมัติสามารถอนุมัติ/ปฏิเสธคำขอลาพร้อมบันทึกเหตุผลได้
  4. HR สามารถบันทึกและยืนยันการขาดงานได้
  5. พนักงานสามารถยื่นคำขอเบิกล่วงหน้าและติดตามยอดคงเหลือได้
  6. ระบบสร้าง Payroll Period ตาม Pay Schedule ที่ผู้มีสิทธิ์ตั้งค่าได้
  7. Payroll แสดงรายละเอียดรายได้ รายการหัก และยอดสุทธิรายบุคคลได้
  8. Salary Advance ที่เข้าเงื่อนไขถูกหักเต็มจำนวนยอดคงค้าง โดยไม่หักซ้ำ และมี Ledger ตรวจสอบได้
  9. Payroll ที่ปิดรอบแล้วไม่สามารถแก้ไขโดยผู้ไม่มีสิทธิ์ได้
  10. พนักงานเห็นเฉพาะข้อมูลและ Payslip ของตนเอง
  11. ผู้มีสิทธิ์เรียกดูรายงานและ Audit Log ได้
